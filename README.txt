Музей Карагандинского колледжа технологии и сервиса
Распакуйте архив целиком и запустите museum.exe. Папка data должна находиться рядом.
Стартовый экран открывает историю колледжа. Коснитесь имени в списке, чтобы открыть карточку директора. Кнопка «История колледжа» возвращает к летописи.
Русский, казахский и английский языки, размер текста, контраст и диктор переключаются на верхней панели. В режиме «Контраст» страницы и фотографии переключаются мгновенно.
Выход — кнопка «Выход» или Ctrl+Shift+Q. Начальный PIN — 1234. Чтобы задать свой PIN, нажмите «Сменить PIN», введите действующий код, затем дважды новый (3–12 цифр). После пяти неверных попыток ввод блокируется на минуту.
Даты руководства взяты из подписей в «На проверку стнеды (1).pdf». Для Цаплина указан период стенда, 1956–1966. Биографии и летопись дополнены по стендам и очерку «От первых мастерских. 2 вариант». Фотографии взяты из стендов и College_History_Slideshow.pdf. Для каждого изображения источник и страница указаны в info.json. Эмблема колледжа — с официального сайта kktis.edu.kz.
История хранится в data/college.json. Для каждого директора в data есть отдельная папка с info.json. Поместите в неё портрет с именем portrait.jpg или portrait.png. Для пополнения архива скопируйте фотографии в data/<фамилия>/Фото, видеоролики в data/<фамилия>/Видео. Например, фото Мамировой положите в data/Мамирова/Фото. Дождитесь окончания копирования и дважды нажмите «Обновить архив.exe». Утилита создаёт недостающие папки и обновляет ленту действующего киоска. Если открыт полноэкранный просмотр, вернитесь в карточку. При следующем запуске киоск также прочитает материалы.
Поддерживаются JPG, JPEG, PNG, BMP, WebP и видео MP4, M4V, MOV, MKV, WebM. Рекомендуемый формат для Windows — MP4 с видео H.264 и звуком AAC. Кодек внутри файла должен поддерживаться плеером. Видеоролики в ленте отмечены кнопкой ▶. Название файла становится подписью. Для переводных подписей в captions можно указать, например, "Видео/Встреча.mp4". Старые фотографии рядом с info.json также остаются в ленте.
Обновление с версии 1.3: закройте киоск по PIN, скопируйте museum.exe и «Обновить архив.exe» рядом с вашими data и config.json, запустите «Обновить архив.exe», затем museum.exe.
Для запуска из исходника используйте run_test.bat, для сборки — build.bat.
Для переноса портретов из презентации закройте киоск, запустите import_portraits.bat, выберите PPTX, изображение и директора. Можно выделить портрет мышью на общем слайде. Сохраните портреты и запустите киоск снова.
