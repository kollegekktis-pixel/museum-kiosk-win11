Тест музея-киоска.
1) Установите Python с python.org (галочка "Add to PATH").
2) Двойной клик по build.bat -> получится museum.exe.
   (или run_test.bat - запустить без сборки)
3) Запустите museum.exe. Выход: кнопка "Выход" внизу слева (или Ctrl+Shift+Q), пароль 1234.

Папка директора: portrait.jpg - портрет (в углу и на иконке в списке), остальные фото - архивные внизу.
Языки: в info.json поля name/years/description/captions можно задавать словарём {"ru":..,"kk":..,"en":..}.
Кнопки сверху: язык, A-/A+ (размер текста), Контраст (для слабовидящих), Диктор (озвучка голосом Windows).
Масштаб интерфейса подстраивается под разрешение экрана автоматически.
