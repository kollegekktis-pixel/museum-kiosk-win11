Музей Карагандинского колледжа технологии и сервиса
Распакуйте архив целиком и запустите museum.exe. Папка data должна находиться рядом.
Стартовый экран открывает историю колледжа. Коснитесь имени в списке, чтобы открыть карточку директора. Кнопка «История колледжа» возвращает к летописи.
Русский, казахский и английский языки, размер текста, контраст и диктор переключаются на верхней панели.
Выход — кнопка «Выход» или Ctrl+Shift+Q. Начальный PIN — 1234. Измените его перед установкой командой museum.exe --setpin 5678, подставив свой код.
Летопись и биографические сведения подготовлены по документу «От первых мастерских. 2 вариант». Эмблема колледжа — с официального сайта kktis.edu.kz.
История хранится в data/college.json. Для каждого директора в data есть отдельная папка с info.json. Поместите в неё портрет с именем portrait.jpg или portrait.png. Остальные фотографии появятся в архивной ленте.
Для запуска из исходника используйте run_test.bat, для сборки — build.bat.
Для переноса портретов из презентации закройте киоск, запустите import_portraits.bat, выберите PPTX, изображение и директора. Можно выделить портрет мышью на общем слайде. Сохраните портреты и запустите киоск снова.
